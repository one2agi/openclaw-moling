assistant: 这是一个 **API Key 动态获取脚本**，原理如下：

## 🔧 原理

### 1. 在 `settings.json` 中注册

```json
"apiKeyHelper": "/home/morav/.claude/apikey-helper.sh"
```

### 2. Claude Code 需要 API Key 时执行这个脚本

```
Claude Code 需要认证
    ↓
执行 apikey-helper.sh
    ↓
脚本返回 API Key（通过 echo）
    ↓
Claude Code 使用这个 Key
```

### 3. 脚本内容

```bash
#!/bin/bash
echo "sk-cp-UJ4PE_lm654VJ9ZR6FzOGg9HBjkzJpKXdYJmgitTrff30LQ4vdaDe_DlGA0q9WO_f-HjeVK2eycV6n23uPNZUzLzC6B8he6IFUsX8NrK9QUkOZeT2sdlzNU"
```

---

## 💡 为什么这么做？

| 直接写在 settings.json | 用 apikey-helper.sh |
|------------------------|----------------------|
| ❌ 可能被 git 追踪/泄露 | ✅ 脚本可加入 `.gitignore` |
| ❌ 共享配置时暴露 Key | ✅ Key 单独管理 |
| ❌ 改 Key 要改两个地方 | ✅ 改脚本一处搞定 |
| ❌ 明文看到 Key | ✅ 其他用户执行脚本才知道 Key |

---

## 🔐 安全优势

```
settings.json      → 只有脚本路径，没有真实 Key
apikey-helper.sh  → 真实 Key（可设 chmod 600 保护）
                    → 可加入 .gitignore
                    → 可加密或从密钥管理器读取
```

**这就是为什么配置里看到的是脚本路径，而不是明文 Key。**
