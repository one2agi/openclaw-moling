---

## 核心能力

| 场景 | Vercel 擅长 |
|---|---|
| **Next.js / React / Vue 应用** | 一键部署，自动 CI/CD |
| **静态网站 / 文档站** | 免费 CDN，全球加速 |
| **SSR / API Routes** | Serverless 函数处理后端逻辑 |
| **前端性能优化** | 自动图片优化、代码分割、边缘渲染 |

---

## 典型用户

```
个人开发者 → 放作品集、博客、Side Project
创业公司   → 快速迭代，不养运维
前端团队   → 前端代码一推送就自动上线
```

---

## 它不是什么

- ❌ **不是 VPS** — 不能装系统、没有 SSH root、跑不了持久进程

- ❌ **不是数据库平台** — 需要另接 Vercel Postgres / Turso / Supabase
- ❌ **不是 AI Agent 平台** — 无状态模型不适合长期运行的 Agent
